Install on Android

एंड्रॉइड पर इंस्टॉल — Play Store से

Play Store se install hota hai — koi file download nahi, koi "unknown source" nahi. Bas apna Gmail do, phir install.

STEP 1

Apna Gmail bhejo

Jo Gmail is phone ke Play Store mein hai, wahi likho. (Settings → Google mein dikhta hai.)

Bhejne ke baad 30 minute ke andar aapka Gmail tester list mein jud jaata hai. Phir Step 2.

STEP 2

Install from Play Store

30 min baad ye link kholo → Accept invite → Download it on Google Play → Install.

Open in Play Store →

"App not available" dikhe = Gmail abhi list mein nahi juda. Thodi der baad phir try karo, ya neeche wala APK.

Pehle se APK wala Simplicity laga hai? Use uninstall karo, phir install.

AFTER INSTALL

Sign in & allow

Apna employee code daalo → Sign in. Phir: Notifications Allow · Location Allow all the time · Background use Allow.
